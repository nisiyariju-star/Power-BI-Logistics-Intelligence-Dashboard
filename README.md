# Power-BI-Logistics-Intelligence-Dashboard
An interactive Power BI dashboard built on 11,000+ logistics shipment records, enabling real-time monitoring of operational performance and key supply chain metrics.

## Overview
This project transforms raw shipment data into an actionable business intelligence dashboard, covering shipment status, delivery performance, revenue, costs, vehicle utilization, warehouse operations, and route efficiency.

## Key Features
- **Data preparation:** Cleaning, transformation, and preparation performed in Microsoft Excel to ensure data quality and reporting accuracy before loading into Power BI.
- **Dynamic visualizations:** Multiple report views analyzing shipment status, delivery performance, revenue and cost trends, vehicle utilization, and route efficiency.
- **KPI-driven reporting:** Interactive filters and slicers built on top of core KPIs to support data-driven decision-making across supply chain operations.

## Tools Used
- Power BI (data modeling, DAX, visualizations)
- Microsoft Excel (data cleaning and preparation)
